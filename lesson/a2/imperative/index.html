Повелительное наклонение

Образование императива, вид в просьбах, давай(те), пусть, вежливые просьбы.

Повелительное наклонение (императив) нужно, чтобы просить, приказывать, советовать, приглашать: Читай! Скажите, пожалуйста… Садитесь! Форма на -те — для «вы» (вежливо или многим людям).

Образование: от основы настоящего (простого будущего) времени

Берём форму они, убираем окончание -ут/-ют/-ат/-ят и смотрим на основу.

ОсноваСуффиксПримеры (они → ты / вы)
на гласный-й (-йте)чита-ют → читай, читайте; рису-ют → рисуй; откро-ют → открой
на согласный, ударение на окончании (я пишУ)-и (-ите)пиш-ут → пиши, пишИте; говор-ят → говори; ид-ут → иди; скаж-ут → скажи
на согласный, ударение на основе (я встАну)-ь (-ьте)встан-ут → встань; ответ-ят → ответь; готов-ят → готовь; забуд-ут → забудь
⚠️ Исключения
давать → давай; вставать → вставай; узнавать → узнавай (суффикс -ва- сохраняется)
дать → дай; есть → ешь; пить → пей; быть → будь
лечь → ляг; сесть → сядь; ехать / поехать → поезжай
📝 Глаголы на -ся
После согласного — -ся, после гласного — -сь: учись — учитесь, умывайся — умывайтесь, садись — садитесь.
💡 Ударение различает формы
Вы пИшете (вы сейчас пишете) — ПишИте! (просьба). Вы смОтрите — СмотрИте!

Вид глагола в императиве

СитуацияВидПример
Конкретная просьба, одно действиеСВОткройте, пожалуйста, окно. Позвони мне вечером.
Приглашение, разрешение (вежливо)НСВВходите! Садитесь! Берите, пожалуйста, торт.
Совет на будущее, регулярное действиеНСВЗвони мне каждый день. Пишите чаще!
Просьба продолжать / начать (поторопить)НСВРассказывай дальше! Ну, говори же!
Запрет (не + …)НСВНе открывайте окно. Не опаздывай.
Предупреждение об опасности (не + …)СВНе упади! Не забудь паспорт!

Совместное действие и третье лицо

  • Давай(те) пойдём в кино!
    давай + 1 л. мн.ч. СВ: Kinoga boraylik!
  • Давай поговорим.
    одно действие → СВ
  • Давай читать вместе каждый вечер.
    давай + инфинитив НСВ — процесс, регулярность
  • Пусть он позвонит мне.
    пусть + 3-е лицо: U menga qo'ng'iroq qilsin.

Вежливые просьбы

  • Скажите, пожалуйста, где остановка?
  • Будьте добры, передайте соль.
  • Не могли бы вы помочь мне?
  • Извините, повторите, пожалуйста.
⚠️ Типичные ошибки узбекоговорящих
✗ Едь!, Ехай! → ✓ Поезжай!
✗ Ляжь! → ✓ Ляг!
✗ Ложи книгу на стол → ✓ Положи книгу на стол.
✗ Не забывай паспорт! (о единственной поездке) → ✓ Не забудь паспорт!
✗ Дай мне помочь (в значении «помоги») → ✓ Помоги мне.

В гостях

Хозяйка
Здравствуйте! Проходите, пожалуйста! Раздевайтесь. НСВ — вежливое приглашение
Гость
Спасибо! Это вам — возьмите, пожалуйста, торт.
Хозяйка
Ой, спасибо! Садитесь за стол. Угощайтесь!
Гость
Всё очень вкусно! Дайте, пожалуйста, рецепт плова. СВ — конкретная просьба
Хозяйка
Конечно! Запишите…
✏️ Образуйте императив (ты / вы): читать, писать, ответить, вставать, сесть, помочь, отдыхать.
✅ читай(те), пиши(те), ответь(те), вставай(те), сядь(те), помоги(те), отдыхай(те).
✏️ Выберите вид: 1) (Закрывайте / Закройте) дверь, пожалуйста. 2) Не (опаздывайте / опоздайте) на урок! 3) (Входите / Войдите), не стесняйтесь! 4) Не (простудись / простужайся) — на улице холодно!
✅ 1) Закройте (конкретная просьба); 2) опаздывайте (запрет — НСВ); 3) Входите (приглашение); 4) простудись (предупреждение — не + СВ).

Термины

Повелительное наклонение
Форма глагола, выражающая просьбу, приказ, совет.
Пример: Читай! Скажите!
🇺🇿 buyruq mayli
Императив
То же, что повелительное наклонение.
давай(те)
Слово для приглашения к совместному действию.
Пример: Давайте начнём!
пусть
Частица для пожелания или приказа третьему лицу.
Пример: Пусть он подождёт.
🇺🇿 -sin
поезжай
Императив глаголов «ехать / поехать».
Пример: Поезжай на метро.
Вежливая просьба
Просьба с «пожалуйста», «будьте добры», «не могли бы вы».
Пример: Будьте добры, помогите.
Запрет
Отрицательный императив, обычно НСВ.
Пример: Не курите!
