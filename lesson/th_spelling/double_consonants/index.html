Двойные согласные

Когда пишутся две одинаковые согласные подряд.

Двойные согласные чаще всего появляются там, где «встречаются» две морфемы: приставка и корень, корень и суффикс, две части сложного слова. Есть и слова, где двойные согласные надо просто запомнить.

ГдеПочемуПримеры
приставка + кореньприставка кончается той же буквой, с которой начинается кореньрас+сказ → рассказ, в+вести → ввести, без+звучный → беззвучный, от+толкнуть → оттолкнуть
корень + суффикскорень на н + суффикс -н-сон → сонный, длина → длинный, лимон → лимонный
сложносокращённые словаконец первой части и начало второйроддом, главврач, спортторг
русские слова (запомнить)сложилось историческиссора, жужжать, дрожжи, вожжи, можжевельник, ванна
заимствованные словапришли из других языковаллея, аппарат, грамм, группа, класс, коллектив, металл, миллион, программа, профессия, территория, эффект
📌 Правило «стыка»
Если приставка оканчивается на ту же согласную, с которой начинается корень, пишем две буквы: рас+сыпать = рассыпать, под+держать = поддержать, от+тащить = оттащить, воз+звание = воззвание.
⚠️ Двойная согласная может исчезать
В заимствованиях при образовании новых слов одна буква иногда «выпадает»: колонна — колонка, кристалл — кристальный, финн — финский, оперетта — оперетка. Но сохраняется: группа — группка, программа — программка, класс — классный, грамм — граммовый.
📝 Список для запоминания
аккуратный, аллея, аннотация, аппарат, аппетит, ассистент, ассортимент, аттестат, баллада, баллон, баррикада, бассейн, грамм, грипп, группа, дискуссия, иллюзия, иллюстрация, касса, класс, коллега, коллекция, колонна, комиссия, комментарий, корреспондент, коррупция, массаж, металл, миллион, оппонент, параллель, пассажир, программа, прогресс, профессия, сессия, сумма, территория, терраса, теннис, тонна, троллейбус, эффект.
⚠️ Не удваивайте лишнего
С одной буквой пишутся: галерея, алюминий, коридор, кавалерия, литература, карикатура. Только одна из согласных двойная: профессор (одна «ф», две «с»), режиссёр (одна «р», две «с»), дилемма (одна «л», две «м»), процесс (одна «ц», две «с» в конце).
💡 Мнемоника
«У профессора один факультет и два студента-ассистента»: одна «ф», две «с». «Коллектив — две «л»: в коллективе всегда больше одного».

Примеры

  • Беззаботный рассказчик поддержал разговор.
  • Пассажиры троллейбуса вышли на аллею.
  • В классе висит иллюстрация к рассказу.
  • Колонна — колонка; кристалл — кристальный.
✏️ Вставьте одну или две буквы: ра(с/сс)вет, бе(з/зз)убый, ко(л/лл)ектив, гру(п/пп)а, профе(с/сс)ор, ко(р/рр)идор, гале(р/рр)ея, дли(н/нн)ый, коло(н/нн)ка, ми(л/лл)ион.
✅ рассвет (рас+свет), беззубый (без+зуб), коллектив, группа, профессор, коридор, галерея, длинный, колонка (от «колонна», одна «н»), миллион.

Термины

Двойные согласные
Две одинаковые согласные буквы подряд в слове.
Пример: рассказ, группа
Стык морфем
Место соединения двух морфем, где часто возникают двойные согласные.
Пример: рас-сказ, лимон-н-ый
Заимствованное слово
Слово, пришедшее из другого языка; часто содержит двойные согласные.
Пример: аллея, металл

Сложносокращённое слово
Слово, образованное из сокращённых частей нескольких слов.
Пример: роддом, главврач
Приставка
Значимая часть слова, стоящая перед корнем и служащая для образования новых слов.
Пример: рас-, под-, без-
🇺🇿 prefiks
Суффикс
Значимая часть слова, стоящая после корня и служащая для образования новых слов или форм.
Пример: -н- в слове «лимонный»
