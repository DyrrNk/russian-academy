Пробный тест №3 (с текстом)

25 вопросов по языку + 5 вопросов по тексту.

Пробный тест составлен по темам, которые традиционно встречаются в вопросах по русскому языку: орфография, пунктуация, лексика, морфология, синтаксис, орфоэпия, текст. Это тренировочный тест, а не официальный вариант Агентства; в реальном блоке «Родной язык» вопросов меньше (10), поэтому здесь — тройной объём для тренировки.

💡 Как работать
Решайте без подсказок и словарей, засекайте время. После теста разберите каждое объяснение, а ошибки выпишите в отдельную тетрадь.

Вопросов: 30. Время: 50 мин.

  • Часть 1. Орфография
  • Часть 2. Пунктуация
  • Часть 3. Лексика и морфология
  • Часть 4. Орфоэпия
  • Часть 5. Работа с текстом
